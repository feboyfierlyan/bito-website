# Bito — Hai. Aku Bito.

A character-led website for Bito. One persistent Rive character moves from the opening greeting into the bottom-right corner of a laptop screen. Drag Bito, open its chat, watch three scroll-led feature conversations, and find the macOS or Windows download.

Serve `dist/` with a static HTTP server. No build step or dependency installation is needed. Run `node scripts/check.cjs` for geometry, asset, anchor and source checks.

GSAP 3.15.0, ScrollTrigger, Flip and Draggable are vendored. Plus Jakarta Sans is stored locally. The original Bito poster is preloaded and stays visible while one persistent Rive runtime renders into a hidden buffer. A 32×32 transparency/color probe rejects black, blank and incomplete frames before copying them to the visible canvas. Two valid frames are required for the initial handoff; the poster fades only after the animation surface is visible. Invalid later frames leave the last good frame intact. Resizing the hidden surface is idempotent and the visible surface changes size only when a valid replacement is ready. The page respects reduced motion and has a footer motion toggle. The interactive scenes are explicitly illustrative, stay inside the webpage and do not call AI or collect messages.

All downloads point to the existing v0.5.1 desktop release. AI access in the desktop app remains limited to invited demo accounts. See THIRD_PARTY.md and dist/assets/ for third-party licenses.

The October 26 desktop-paper revision centers the hero on a white, light gray dotted canvas. Small native-style preview windows and pastel stickers surround the persistent animated Bito. Mac and Windows have direct download links; the action preview jumps into the original interactive desktop story. The existing Site identity and URL are preserved. CSS/assets/anchors/geometry checks run automatically; visual browser review is left to the owner.

Desktop objects can be freely dragged using mouse or touch. Stickers, a locally hosted rotating-flower GIF, and desktop icons retain their drop positions until reload. Preview windows are fixed and cannot be dragged. Pickup/sway animates a separate inner surface, so the grab point remains stable. A 6px threshold separates clicks from drags; capture-phase click suppression prevents accidental navigation after release. Arrow keys move focused objects; Shift increases the step. Bounds refresh on resize, and the GIF uses a still image when motion is reduced or the scene is hidden. The large preview window stays anchored; clicking it opens the interactive example. App icons are decorative and do not claim Word/Excel/PDF automation in the app.

Hovering the reminder, hello note, or small chat window spotlights that window and gently fades the other desktop objects. Keyboard focus produces the same treatment. The three small windows stay level at rest and on hover. Hover scales the reminder from its top-left corner, the hello note from its top-right corner, and the chat preview from its bottom-right window corner (excluding its filename row). Each anchored corner stays fixed during the transition. The headline and download controls remain readable. Opacity and pickup effects run on inner surfaces, separate from drag coordinates and the scroll timeline. Fine-pointer hover is excluded on touch screens; reduced-motion preferences remove the lift transitions.

The small windows scale to 107.5% over 480ms on hover, returning smoothly from their current size when interrupted. During scroll, the full desktop-object group shares the hero title's upward movement and fade on the same timeline. Individual sticker drag offsets remain local to that group.

The laptop story uses the supplied 1920×1440 mockup (dist/assets/laptop-workspace.png) without altering it. Scroll first reveals the laptop, then zooms into the lower-right workspace: its left and top move out of frame while the right bezel and bottom edge remain visible. The original Rive actor travels into that corner and grows with the camera. HTML chat and greeting sit over the measured screen rectangle. On narrow screens the camera moves toward the right-hand workspace, keeping Bito and chat readable. Drag/chat bounds use the intersection of the screen and viewport. Reduced motion goes directly to the interactive final composition. The former simulated onboarding panel is removed.

The interactive scene preserves a dropped drag offset and blends it back along the scroll path, with zero velocity at the handoff. Chat translation and panel reveal use separate nested surfaces. A single reversible reveal timeline carries the panel and all its contents together; interrupted clicks reverse the current motion. Side changes use transform easing with a clearance buffer, and placement measures the stable drag box rather than the waving character. The notification and initial transcript message stay mounted. The numbered chapter caption is removed.

Run node scripts/check.cjs, node scripts/check-stickers.cjs and node scripts/check-scene-motion.cjs for the layout, bounds, source, drag and interruption checks. Manual visual testing remains with the owner.

Run node scripts/check-rive-presentation.cjs to check startup black frames, transparent loading frames, invalid frames after readiness, resize handoff and cleanup without manual browser testing.

The former personality selector and small-actions tabs are replaced with three alternating feature stories: conversation, reminders and file creation. The story nearest the reading line scales up and becomes fully opaque; neighboring rows ease smaller and fade. Each entry restarts a local typed prompt, a typing indicator, and a Bito response. Leaving cancels the sequence and all pending motion. The windows are explicitly labeled video placeholders, with no fake playback controls. Reduced motion shows the complete conversations; the footer toggle applies as well. Run node scripts/check-feature-stories.cjs for reentry, cancellation, reading-line selection and reduced-motion checks.

Feature messages use a small animated surface that grows in width and height from the visible text prefix. Hidden text measurements are positioned out of flow; only external slots reserve the completed message height. Ink clips inside the rounded surface and wraps at a stable column width. GSAP quickTo eases dimension changes without restarting the conversation; ResizeObserver and font readiness refresh measurements. User bubbles always anchor right, Bito bubbles/typing left, including the reversed second row.

Feature stories use a compact 1080px composition and 62svh row spacing (460–620px), with content-driven minimum height and smaller conversation typography. At the reading line the composition eases to 102.5%; neighbors ease to 91% and 30% opacity, keeping nearby features visible. Scale stays inside each fixed-layout row, and interrupted scrolling retargets the current tween. Mobile highlights remain at 100% to preserve safe edges; reduced motion shows all rows at natural size. No video assets or page URLs change.
